# Tshokay Dorji, Web CV

Personal web CV of Tshokay Dorji, Full Stack Developer, AI Engineer and Cybersecurity student in Thimphu, Bhutan.
Built on the "Purposeful Overthinker" personal brand.

A single static page: `index.html` (HTML, CSS and JavaScript in one file, no build step).

## Run locally
Open `index.html` in a browser.

## Deploy
- GitHub Pages: Settings, Pages, Deploy from a branch, `main`, `/ (root)`.
- Render: New, Static Site, connect this repo, leave Build Command empty, Publish Directory `.`.
